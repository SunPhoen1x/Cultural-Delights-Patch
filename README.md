# Polymer Patch for Cultural Delights

This is a patch for [Cultural Delights Delight](https://modrinth.com/mod/cultural-delights), making it work fully server side, with all of its functionality intact.

Cultural Delights is required and not included within this mod.

This mod requires server resource pack, about which setup you can read here: https://polymer.pb4.eu/latest/user/resource-pack-hosting/

You can read more about [Cultural Delights on it's Modrinth page!](https://modrinth.com/mod/cultural-delights)
